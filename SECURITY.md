# Security Policy

This repository is part of the SZL Holdings governed-AI estate and follows its
fail-closed doctrine.

## Supported versions

Only the default branch is supported.

## Reporting a vulnerability

Use GitHub's private security reporting on this repository. Do not open a
public issue for a suspected vulnerability.

## Handling

- Suspected vulnerabilities are triaged fail-closed: assume impact until ruled out.
- Fixes land through the branch / PR / CI lane (direct pushes to the default
  branch are blocked org-wide).
